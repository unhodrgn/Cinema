팀프로젝트 기말 프로젝트 발표 기준 및 사전 준비 사항 안내

- 초기 환경 설정, 사용한 데이터베이스(DBMS), 개발 언어, 부가 프로그램(프레임워크, 컨테이너, 협업 도구 등) 설명할 것

- 데이터베이스(백엔드 서버)와 클라이언트(웹/앱 프론트엔드)는 반드시 논리적, 물리적으로 분리된 아키텍처로 구현할 것

발표는 단순한 기능 나열이 아니라.. 기획부터 설계, 구현, 검증까지 스토리 라인으로 구성

발표 자료(PPT): 양식은 자유롭게 구성

진행 시간 : 팀 당 발표 15분(연습 필요) + 질의응답 5~10분으로 진행

발표 및 시연 : 기준은 1명 (상황에 따라 2명 이상)

시연 환경 사전 세팅: 발표 시작과 동시에 즉시 시연할 수 있도록 프로그램 실행 환경과 PPT를 미리 완벽히 세팅해 둘 것. (발표 중 발생하는 사전 환경 설정 오류 및 실행 장애는 전적으로 해당 팀의 책임)

데이터 제어용 SQL 쿼리 준비: 시연 중 데이터 상태 변경, 예외 상황 테스트, 권한 검증 등을 즉시 보여줄 수 있도록 데이터 제어가 가능한 SQL 쿼리 스크립트를 미리 작성하여 대기할 것

평가 사항 : 발표 스토리, 우리 프로젝트만이 가진 핵심 기능, 기술 이해도, 설계 견고성, 창의성 또는 완성도

마지막 페이지 (또는 중간 페이지): [AI가 모든 것을 다 해주는 시대에 팀 단위 프로젝트가 왜 의미가 있는가?] 의미가 있다면 그에 대한 설명, 의미가 없다면 왜 그런지 팀프로젝트를 수행한 경험을 바탕으로 설명
